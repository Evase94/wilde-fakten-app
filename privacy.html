2. Whose data

Wilde Fakten Uploader is used only by the operator. It does not collect data from other people, has no user accounts and does not track visitors. This website sets no cookies and uses no analytics.

3. Data from TikTok

When the operator connects their own TikTok account, the tool receives from TikTok:

  • an access token and a refresh token, to upload videos on the operator's behalf;
  • the account's open ID and display name (scope user.info.basic), to show which account is connected;
  • the upload ID and status of each uploaded video (scope video.upload).

This data is stored only in local files on the operator's computer. It is not sent to any server other than TikTok's own API, not sold and not shared with third parties.

4. Videos

The tool uploads only videos the operator created and approved. Upload goes directly to TikTok's API.

5. Retention and deletion

Tokens are kept until the operator disconnects the tool. Access can be revoked at any time in the TikTok app (Settings and privacy → Security → Manage app permissions); the operator then deletes the local token file.

6. Your rights

Under the GDPR you have the right to access, correct and delete your data and to complain to a supervisory authority. As the tool processes only the operator's own account data, requests can be sent to the contact above.
